## 🛡️ `./security-labs.sh`

My security side quest is a serious one: **understand how systems fail so I can help make them safer**.

- 🔐 **Hardening:** securing services, least privilege, and secret hygiene.
- 🕵️ **OSINT & reconnaissance:** understanding exposure in authorized labs.
- 🧪 **Pentesting fundamentals:** practicing safely and documenting findings.
- 🚩 **CTF learning:** [Hack The Box](https://www.hackthebox.com/) and [TryHackMe](https://tryhackme.com/) labs covering Linux privilege escalation, OWASP-style web vulnerabilities, authentication issues, and misconfigurations.
